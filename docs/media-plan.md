- Площадка закупки: [Telega.in](https://telega.in/).
- Этап: подготовлена первая тестовая волна платных размещений.
- Лимит волны: **7 000 ₽**.

## 5. Аналитика и ссылки

Для всех размещений используется единая разметка:

- `utm_medium=paid_post`;
- `utm_campaign=put_men_2026`;
- отдельный `utm_source` для каждого канала;
- конечная страница: `https://menway.pro/about`.

Короткие ссылки `/go/61–/go/64` внесены в рабочий файл ссылок, настроены на сервере и готовы к использованию. Проверка через `curl` подтвердила для всех четырёх ссылок: ответ `HTTP 302 Found`, переход только по HTTPS, сохранение всех UTM-параметров, успешный ответ страницы `/about` со статусом `HTTP 200 OK` и отсутствие циклических перенаправлений.

Техническая проверка редиректов завершена. Перед оплатой размещений остаётся выполнить по одному контрольному переходу в обычном браузере и убедиться, что визиты и UTM-источники появляются в правильном счётчике Яндекс Метрики.

Основные цели Яндекс Метрики:

- регистрация в Telegram — `pm_registration_tg`;
- регистрация в MAX — `pm_registration_max`;
- переход на страницу теста — `pm_test_open`;
- завершение теста — `pm_test_complete`.

## 6. Порядок запуска после пополнения баланса

1. Повторно проверить цену, прогноз просмотров и доступность каждого канала в Telega.in.
2. Не превышать общий лимит **7 000 ₽** без отдельного согласования.
3. Выполнить контрольные переходы по `/go/61–/go/64` в браузере и подтвердить отображение UTM-источников и целей в Яндекс Метрике; серверная проверка редиректов уже завершена.
4. Подготовить отдельные версии объявления для Telegram и MAX с соответствующим призывом.
5. Настроить кампанию и расписание размещений.
6. До оплаты показать итоговую корзину на согласование.
7. После публикаций зафиксировать фактические просмотры, переходы, регистрации Telegram и MAX, конверсию и стоимость регистрации.
