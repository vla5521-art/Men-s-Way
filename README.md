# Лендинг «Путь мужчины» — версия 2.0

Production-ready React/Vite лендинг самостоятельного онлайн-курса для мужчин.

## Что вошло в версию 2.0

- новая последовательная структура лендинга;
- переработанные тексты;
- блок узнавания себя;
- расширенное описание программы;
- блок ожидаемых результатов без гарантий;
- блок наставничества и сообщества;
- обновленный FAQ;
- сохраненный блок участия за добровольное пожертвование;
- сохраненные реальные контакты;
- сохраненная конфигурация социальных сетей;
- сохраненный счетчик до 20 сентября 2026 года;
- сохраненная форма заявки и поддержка `VITE_FORM_ENDPOINT`.

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel через **Add New → Project**.
2. Выберите Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. При наличии рабочего обработчика заявок добавьте `VITE_FORM_ENDPOINT` в Environment Variables.
6. Нажмите **Deploy**.

Файл `vercel.json` сохраняет SPA rewrite на `index.html`.

## Контент и конфигурация

Тексты, параметры курса, контакты, ссылки и флаги видимости находятся в `src/data/content.ts`.

Счётчик Яндекс Метрики `112421066` подключён через публичную переменную `VITE_YANDEX_METRIKA_ID` в `.env.production`. Сайт отправляет цели просмотра программы и регистрации, намерения зарегистрироваться и переходов в Telegram/VK.

Секции преподавателей и отзывов скрыты, пока нет подтвержденных данных. Блок социальных сетей скрыт, пока не добавлены реальные URL. Пустые технические заглушки пользователю не показываются.

## Форма

Форма сохраняет существующий JSON POST-контракт:

```json
{
  "name": "Имя",
  "contact": "Телефон или Telegram",
  "email": "mail@example.com",
  "consent": true
}
```

Для реальной отправки скопируйте `.env.example` в локальный env-файл и укажите HTTPS endpoint. Не добавляйте секреты в переменные с префиксом `VITE_`.

## Временные ограничения

- реальный URL обработчика формы не хранится в репозитории;
- номер контакта для Казахстана не опубликован, потому что в исходной версии он не был подтвержден;
- ссылки Telegram, Instagram, Rutube и YouTube отсутствуют в исходной версии и не выводятся;
- `public/sitemap.xml` содержит временный домен `example.com`, который нужно заменить после назначения production-домена.
